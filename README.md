## Mbilse CLI

### Install MbilseCLI

Try curl:

```bash

curl -fsSL https://mbilseserv.github.io/mbilseshapp/setup.sh | sh

```

Then Set this:

```bash

mbilseapps update-this
mbilseapps all-pkg-install  

```
